# My Daily Planner 🌸

A beautiful pastel productivity app built with **React + Vite + Tailwind CSS v4**.

## Features

- 🗓️ **Dashboard** – Overview of habits, schedule, mood, water & notes
- 📅 **Schedule** – Daily/weekly calendar
- ✅ **Habit Tracker** – Build streaks
- ⏱️ **Focus Timer** – Pomodoro sessions
- 😊 **Mood Journal** – Emotional wellbeing tracker
- 📝 **Notes** – Personal notebook
- 💧 **Water Tracker** – Daily hydration
- 🤖 **AI Assistant** – Personal planning coach
- ⚙️ **Settings** – Customization

## Tech Stack

- **React 19** with Vite 6
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Nunito** Google Font
- Pastel theme: soft pink, lavender, mint, peach, baby blue
- Dark mode toggle
- Responsive: sidebar on desktop, hamburger on mobile

## Getting Started

```bash
npm install
npm run dev
```
